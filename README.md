# Ask

可自托管的结构化研究阅读服务，关注生物、金融、产业及其交叉问题。提前准备有来源、逻辑清楚、简短易懂的内容，阅读时直接打开成品。

**状态：已实现有限试读程序，长期无人值守服务仍在建设。** 实际运行状态以私有实例记录为准。实施进度统一记录在 [任务 #1](https://github.com/maxwelles666/ask/issues/1)。

## 设计方向

- 轻量调度程序、持久化存储和私人阅读网页。
- 服务持续可用，生成任务按内容库存和可配置用量上限调度。
- 已保存内容可独立阅读，普通浏览不调用模型。
- 资料先采集和核查，再生成问题与解读；明确区分事实、推断和证据不足。

每张卡片包含：

> 具体问题 → 一句话结论 → 简短因果解释 → 来源与日期 → 成立条件或反例 → 可观察指标

## 配置与数据

认证方式、账户限额和部署连接由实例所有者在私有环境配置。示例默认关闭生成任务；尚未确认认证与用量控制时，不能启用无人值守生成。

个人配置放在 `.local/`，运行数据放在 `data/`；这些目录不提交到公开仓库。仓库不保存登录令牌、服务器连接资料或私人阅读记录。
