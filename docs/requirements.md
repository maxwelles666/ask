# 功能需求与内容规范

## 阅读体验

手机与电脑浏览器均可使用，支持主题分类、收藏、已读和资料来源展开。首页展示已生成内容、最近成功更新时间、库存及暂停原因。

短卡与专题均提前生成。阅读、切换主题和展开已保存解释不调用模型；没有成品时显示缺少内容或排队状态。生成服务暂停或不可用时，已有内容保持可读。

## 内容组织

以周主题组织相关问题，逐步覆盖机制、证据、约束与变化。候选起始值为每日 10 张短卡和 1 篇专题；实际产量须结合质量、阅读情况和实例预算校准，不作产量保证。

- 短卡参考篇幅：300–500 个中文字。
- 专题参考篇幅：1500–2500 个中文字。
- 每张卡只回答一个明确问题，给出简短的、可核查的解释。
- 关键因果关系注明成立条件；相关性证据不能直接写成因果结论。
- 引用关联到具体论断，记录标题、链接、发表/更新日期和获取日期。
- 区分原始来源事实、分析推断和待验证假设；证据不足就保留待查状态。
- 新内容应增加证据、机制或反例，避免同一观点反复改写。

## 问题模板

| 方向 | 示例 |
| --- | --- |
| 生物 | 一项研究实际证明了什么？从实验结果走向临床应用，还缺哪些证据？ |
| 金融 | 企业利润增长而经营现金流下降，有哪些可能解释？哪些数据可以区分？ |
| 产业 | 技术从样品走向量产，成本、良率、供应链与需求分别形成哪些约束？ |
| 交叉 | 技术突破如何影响生产成本、商业化条件和融资需求？哪些环节仍是假设？ |

## 后台行为

1. 采集资料并保留来源元数据，按内容指纹去重。
2. 根据主题和证据缺口建立有界问题队列。
3. 在认证、用量和库存条件满足时生成草稿。
4. 校验结构、来源支持情况和重复程度，再发布到私人阅读库。
5. 记录任务状态与失败原因；限次重试，恢复时跳过已完成任务。

库存默认目标为约三天阅读量，可配置；达到上限就暂停补货，降至恢复阈值再继续。时效性较强的资料要有过期与更新策略，不能将旧结论标为实时。

## 用量与权限

- 每个实例明确选择认证与计费渠道，配置可验证的用量限制。
- 不能把字数、请求次数、运行时长或进程隔离当作提供方额度限制。
- 达到额度上限、授权失效或无法确认必需的限额条件时，停止新生成任务。
- 不在失败或超限时自动切换到另一计费渠道。
- 限次重试、单任务截止时间和并发限制是额外约束，不能替代提供方的额度控制。
- 阅读入口应有适合私人数据的访问控制。

## 非首版范围

不包含证券交易执行、个体诊疗建议、无限递归研究、付费资料绕过或对外多租户运营。
